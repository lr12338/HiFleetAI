# 历史归档说明

本目录用于保存仍有参考价值、但不再属于当前主阅读路径的历史材料。

## 1. 归档范围

当前已归档内容包括：

- `历史计划/`
  - Phase 0-1 实施计划
  - 第二阶段任务拆分
- `历史快照/`
  - 第二阶段起始快照
- `历史提示词/`
  - 下一位 Agent 提示词旧版
- `历史规范/`
  - 旧版版本管理规范
  - 旧版 Agent 执行协议
- `ADR/`
  - 开发流程相关决策记录

## 2. 使用原则

- 当前开发优先阅读主文档，不要把归档文档当成当前状态说明
- 归档文档主要用于追溯历史决策、阶段拆分与执行背景
- 如果主文档与归档内容冲突，以主文档和最新验证结果为准

## 3. 不在本目录的历史材料

开发日志仍保留在：

- `docs/开发日志/`

因为它们主要承担过程记录职责，而不是历史方案归档职责。
