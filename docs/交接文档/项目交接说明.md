# 项目交接说明

## 1. 当前项目状态

当前仓库已经不是“待补救的候选状态”，而是一个已经完成 Phase 2 收口、并经过最近一轮系统验证的标准客服后台 MVP 基线。

当前已确认：

- 登录与鉴权可用
- 会话列表、会话详情、备注、接管状态流转可用
- `/api/v1/chat` 可用
- Harness `handoff` / `regression` 可用
- 前端 `Test Chat` 可完成浏览器联调

## 4. 当前边界

当前仍然禁止直接进入以下范围：

- 微信公众号真实接入
- Chatwoot 真实接入
- 微信客服平台真实接入
- 文件分析沙箱
- 订阅通知
- 高风险生产写操作
- 伪造 Harness 成功

## 5. 当前最需要保持稳定的部分

- `/api/v1/chat` 响应契约
- `SupervisorRouter` 最小路由行为
- `ModelGateway` 结构化成功/失败行为
- 会话状态流转
- Harness runner 与 deterministic judge

## 6. 当前环境注意事项

最近一轮验证已明确：

- 推荐先使用 SQLite 路径完成本地联调
- PostgreSQL 应用内验证仍被驱动问题阻塞
- Docker Compose 自举受当前账号 Docker 权限限制
- MinIO 最近一轮未完成启动验证

## 7. 当前本地联调最小路径

最稳妥的路径是：

1. 初始化 SQLite：`data/app-dev.db`
2. 创建本地管理员：`admin / admin`
3. 启动后端：`127.0.0.1:8000`
4. 启动前端：`127.0.0.1:5173`
5. 登录后台
6. 进入 `Test Chat`
7. 发送测试消息并跳转会话详情
