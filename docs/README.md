# 文档目录

`docs/` 用于存放 HiFleetAI 的计划、状态、架构、交接与交付文档。

## 必读文档

- `../HiFleetAI开发方案.md`：需求主文档与阶段路线图
- `../Harness驱动开发规范.md`：Harness 驱动开发基线
- `system-overview.md`：系统目标、MVP 范围、当前已实现能力
- `architecture-overview.md`：系统架构与模块关系
- `testing-deployment-maintenance.md`：运行、测试、排障说明
- `development-status.md`：当前开发进展与下一阶段建议
- `phase2-closeout.md`：Phase 2 收口结论
- `agent-handoff.md`：给下一位 Agent 的交接说明
- `next-agent-prompt.md`：可直接复制的接力提示词

## 管理文档

- `implementation-plan.md`：Phase 0-1 历史计划基线
- `phase2-subtasks.md`：Phase 2 细化拆分
- `task-board.md`：任务状态总表
- `versioning-policy.md`：分支、提交、标签与禁止提交文件规则
- `dev-logs/`：主日志与任务日志

## 维护约束

- 不覆盖已经确认的需求主文档
- 不将运行产物、缓存、密钥和本地数据写入文档
- 文档更新应与代码状态和验证结果保持一致
