# Frontend

React + Vite admin-console bootstrap for HiFleetAI Phase 2.

## Scope

This package provides the initial frontend shell required by `P2-01A`:

- React + Vite + TypeScript project structure
- minimal route shell with shared layout and placeholder screens
- `npm test` via Vitest and Testing Library
- `npm run build` via Vite production build

This bootstrap intentionally does not include login logic, real auth, conversation pages, handoff controls, notes, Harness pages, or any live backend/channel integration.

## Commands

```bash
npm install
npm test
npm run build
```
